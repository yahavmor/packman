# Pacman

A Pacman game in vanilla JavaScript.

**Live demo:** https://yahavmor.github.io/packman/

<img width="756" height="704" alt="packman screenshot" src="https://github.com/user-attachments/assets/e12f47e7-0cf8-40e6-afbb-d2f7eed86ba0" />

## Features

- Move Pacman with the arrow keys and clear the board
- Ghosts move on a timer
- Power food lets Pacman eat the ghosts for a while, and eaten ghosts come back later
- Cherries appear in random empty cells
- Score, win and game over screens, with Play again

## Tech

HTML, CSS and vanilla JavaScript, no libraries.

## Run locally

Open `index.html` in a browser.
